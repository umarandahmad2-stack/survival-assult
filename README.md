# Operation: Lost Trio

A Unity 3D tactical survival and rescue game starter project.

## Starter features
- First-person movement and mouse look
- Health and damage
- Hitscan weapon prototype with ammo and reload
- Interactions for rescue objectives and loot crates
- Enemy pursuit AI using Unity NavMesh
- Basic survival HUD and rescue counter

## Setup
1. Create a Unity 3D project (Unity 2022.3 LTS or newer recommended).
2. Copy the `Assets/OperationLostTrio` folder from the starter pack into the project.
3. Add the scripts to scene objects and assign references in the Inspector.
4. Add colliders to interactable objects, configure layers, and bake a NavMesh for enemies.
5. Test and tune movement, damage, weapons, and rescue objectives.

This is a prototype scaffold, not a complete game. You still need to create the scene, models, materials, audio, animations, UI polish, and gameplay balancing. Never commit passwords, API keys, or private tokens.
